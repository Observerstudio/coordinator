People own the judgment. Agents own the build. The hub remembers what both decided. Eight stations in the life of one piece of work, four seats around it. Pick a seat to see only its part.

What flows back

GitHub keeps the code. The hub keeps what the team learned while writing it, ranked into the first block of the next session. This is the part the old workflow did not have.

  1. RulesNever force-push. Lanes never delegate. Every PR passes the gate. Served to everyone, always.
  2. DecisionsGo over TS. VM over Cloud Run. Plugin before daemon. Closed, dated, signed.
  3. BitesWhat bit us, as an imperative with a trigger. Shown before the command runs; denied once.
  4. FactsMeasured, not remembered. Hub latency, environment shape. Expire on a TTL.
  5. HandoffWhere the track is right now. Supersedes the last one. Read first.

Six things that do not bend

  • Build the spec, nothing around it.Do not shrink the product; enhance it. A guard for a caller that does not exist is an issue, not a gate.
  • Never force-push.Amended history goes on a new branch with a new PR.
  • Lanes never delegate.Work happens where it can be seen. A subagent is stopped, its files kept, the lane continues.
  • Idle is not finished.Only the sentinel line is. A quiet pane gets a nudge, not a merge.
  • The coordinator writes no feature code.Briefs, reviews, notes and the skill are its files. Everything else goes to a lane.
  • Findings that live only in chat did not happen.A dated note merged by PR, or a rule, bite or decision on the hub.
