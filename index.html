How a PR moves through a track

People own the judgment. The coordinator owns the gate. Lanes own the typing. The hub remembers. Seven stations, four actors. Every cell links to the thing that enforces it, so this page stays a map, not a manual.

YouAhmed, or whoever owns the track
Say what you want.One line is enough. "Fix the bug" started a lane, a rework and a merge today.
Closed decisions stay closed.Go vs TS, hosting, plugin order live on the hub as decisions. The brief cites them; nobody re-opens them.
Blocked comes to you rarely.Only when the brief reserved a decision and the coordinator can't pick. Answer the ask; work resumes.
Read the score, not the checks.A green CI with an empty review is unreviewed. The scorecard comment on the PR is what you read.
Some merges are yours.The skill repo, and anything the session's permission classifier blocks. The coordinator tells you which.
Every PR teaches Go.The "Go to read here" section is written for you. Skip it and the repo stops being a course.
Coordinatorone session per track
Handoff, memory, repo. In that order.och handoff show, then memory search, then CLAUDE.md. From a cold start, done, in flight and decided all look like todo. SKILL.md, "Your role"
Diagnose, then brief.Worktree and branch, pattern to copy, scope with file:line, test pins, delivery, STOP conditions. Reserved decisions are named, not delegated. Claim the umbrella. lane-brief-template.md
Prompt, wait, read back.herdr agent prompt <pane> "…" --wait --timeout. Brief goes in a file, the prompt carries a pointer. Ghost text in the composer is not input. herdr-runbook.md
Settled is not finished.herdr agent wait, then read the transcript for the sentinel, excluding your own dispatch text. Idle with no sentinel: nudge "continue". Watching for completion
Cold review at the exact sha.Ten-item rubric, /ponytail-review, one mutation per guard, gate.sh check. Then CI green and mergeStateStatus CLEAN. Rework goes back as a review file. review-rubric.md
One command lands it.gate.sh merge <PR> --scorecard --reason --umbrella: comment, squash-merge, release claims, restart the hub, summary. Second of two sibling PRs: re-gate after the first merges. The gate
Findings become files.A dated note merged by PR, then och handoff --name. Something bit you: publish a bite with a trigger so the next agent sees it before the command runs. OCH is the ledger
Lanea pane the coordinator drives
Worktree, claim, read.Create the worktree the brief names, och claim … --parent <umbrella>, read the whole brief before touching code.
Type where it can be seen.Step by step in the pane, ponytail on, one runnable check per non-trivial piece of logic. Never a subagent. A reserved decision comes back as LANE-BLOCKED with options.
One sentinel line.LANE-DONE — <branch> <sha> <summary>. Push, open the PR with a gate-ready checklist and a "Go to read here" section. Then wait for review.
Release your own claim.The child claim is on the lane's token; the coordinator's release returns NOT_OWNER. The gate prints the exact command for you.
Hub and CIOCH plus GitHub
First block of the session.Rules, decisions, bites and the current handoff arrive ranked before anyone types. The HUD line shows unread and handoff name.
Claims collide or nest.och claim answers CONFLICT or SIMILAR when someone is already there. A lane's child claim under the coordinator's umbrella is not a conflict.
Heartbeats are free.The plugin heartbeats on every tool use; a claim that goes quiet expires on its TTL instead of squatting.
Blocked is a question with options.och ask parks the claim; the coordinator sees it in context and answers with och resolve answer.
The sentinel becomes a report.The plugin's Stop hook turns LANE-DONE into och report with the sha as evidence. CI runs the race suite on the PR.
Merge resolves the umbrella.REPORTED children are marked done, others released; the hub restarts only when cmd/ or internal/ changed.
Handoff supersedes handoff.Same name, new id. The next session reads it first; the statusline names it.

Hatched cells: that actor has nothing to do at that station. Scroll sideways on narrow screens.

One PR, as it actually ran

#63, 2026-09-07. A fix to the gate script, proven by merging itself with the script it fixed. Every line below is a real command or a real output from that afternoon.

# take up
och handoff show session-0907-tooling-landed
# brief + claim
och claim --scope repo:och/scripts --intent "gate.sh post-merge fix — coordinator umbrella"
c_sx1ddkrx04 · CLAIMED
# dispatch
herdr agent prompt wE:p8 "/ponytail full — you are LANE-J. read docs/lanes/LANE-BRIEF-gate-postmerge.md …" --wait --until working
herdr agent wait wE:p8 --timeout 580000
LANE-DONE — fix/gate-postmerge 70677f3 gate.sh post-merge steps now never abort
# gate: rework 1 (a duplication the lane had flagged and kept)
herdr agent prompt wE:p8 "Rework requested: read docs/lanes/REVIEW-gate-postmerge-1.md …" --wait --until working
LANE-DONE — fix/gate-postmerge 6ac83d7 rework 1
scripts/gate.sh check 63                    # gofmt, vet, go test -race in .worktrees/gate-63
bash -c 'source scripts/gate.sh --lib; step a true; step b false; step_summary'   # exit 1, as it must
# land
GATE_REPO=$PWD .worktrees/gate-63/scripts/gate.sh merge 63 --scorecard scorecard-63.md \
  --umbrella c_sx1ddkrx04 --reason "gate 10/10 at 6ac83d7; PR #63 squash-merged"
gate: post-merge summary:
  release c_9mvtzqpr6f skipped          # lane-owned; command printed for the lane
  release umbrella c_sx1ddkrx04 ok
  remove gate worktree ok
  make hub-restart ok
# hand off
och handoff "gate.sh post-merge bug fixed and dogfooded (#63) …" --name session-0907-gate-postmerge-fixed

Six things that do not bend

  • Never force-push.Amended history goes on a new branch with a new PR.
  • Lanes never delegate.If a lane spawns a subagent, stop it, keep the files, continue in the pane.
  • Idle is not finished.Only the sentinel line is. A quiet pane gets a nudge, not a merge.
  • The coordinator writes no feature code.Even the urgent fix goes to a lane. Briefs, reviews, notes and the skill are the coordinator's files.
  • One integration slot per machine.Announce, check nothing is live, run it yourself, release the lease.
  • Findings that live only in chat did not happen.A dated note, merged by PR, or a bite on the hub.
