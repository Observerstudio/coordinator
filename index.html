You lead. Agents build. Evidence comes back up.

One person owns every track. Direction flows down through a coordinator to the lanes that type. Proof flows back up as PRs, scorecards and notes. Nothing ships without your read.

You

The leader. Sets the need, closes decisions, approves what ships.
  • Say what you need. One line is enough. Everything below starts from it.
  • Decide once. Stack, scope, order of work. Written into the PRD; nobody re-opens it in chat.
  • Answer only reserved questions. Blocked work reaches you as options, not essays.
  • Approve by evidence. You read the scorecard on the PR, not the green checks. You merge what agents may not.
directionevidence: PRs, scorecards, notes

Coordinator

One Claude Code session per track. Judgment, not typing.
  • Reads before acting. Last handoff, memory, the repo. Done, in flight and decided all look like todo from a cold start.
  • Writes the briefs. Scope with file:line, a pattern to copy, test pins, and the decisions a lane may not make.
  • Gates every PR. Cold review at the exact sha, ten items, one mutation per guard, a pass for over-engineering. Rework goes back as a file.
  • Merges and hands off. Squash-merge, dated note, handoff for the next session. Writes no feature code.

Lane

a pane, one brief
  • Own worktree and branch. Types step by step where it can be seen. No subagents.

What stays

Decisions in the PRD, findings in dated notes, a handoff per session, rules that do not bend. All in the repo, all merged by PR. The next coordinator reads them before it types a word, so you never explain the same thing twice.

Six things that do not bend

  • Build the spec, nothing around it.Do not shrink the product; enhance it.
  • Never force-push.Amended history goes on a new branch with a new PR.
  • Lanes never delegate.Work happens where it can be seen. A subagent is stopped, its files kept, the lane continues.
  • Idle is not finished.Only the sentinel line is. A quiet pane gets a nudge, not a merge.
  • The coordinator writes no feature code.Briefs, reviews and notes are its files. Everything else goes to a lane.
  • Findings that live only in chat did not happen.A dated note, merged by PR.
