From idea to shipped, and remembered

People decide. Agents build. The hub remembers. Eight stations, read top to bottom. On the right, who is at each one.

1

A need shows up

One line is enough. A client, an incident, or a day of friction.

YouSay it. "Nine gate cycles by hand" started a track.
CoordinatorReads the handoff, memory and the repo before acting.
HubServes rules, decisions, bites and the last handoff first.
2

Decide once

Stack, hosting, scope, order. Written down, then closed.

YouClose it. It goes to the PRD and the hub and stays closed.
CoordinatorDiagnoses on real data before anyone builds.
HubServes the decision to every later session.
3

One session owns the track

You talk to the coordinator. It talks to the lanes.

YouOpen the session on the track's handoff.
CoordinatorClaims the track's scope so parallel tracks see each other.
HubSays CONFLICT or SIMILAR if someone is already there.
4

Split into briefs

Each lane gets a scope, a pattern to copy, and the decisions it may not make.

CoordinatorWrites the brief. Reserved decisions are named.
LaneTakes a worktree and a child claim under the coordinator's.
YouHear about it only if a decision was reserved for you.
5

Build, away from keyboard

Typing happens in panes you can watch but don't have to.

LaneImplements step by step, visibly. No subagents.
CoordinatorWaits for the sentinel, nudges stalls, writes no feature code.
YouBlocked work reaches you as a question with options.
6

Every PR passes one gate

One reviewer, ten items, at the exact sha. Green checks are not a review.

LanePrints the sentinel with the sha, opens the PR with a Go section.
CoordinatorCold review, one mutation per guard, ponytail pass. Rework as a file.
CIRuns the race suite; the sentinel becomes a report.
YouRead the scorecard, not the checks.
7

Ship

Squash-merge, release the claims, restart the hub.

CoordinatorLands it in one move. Re-gates the second of two sibling PRs.
LaneReleases its own claim; the pane is reused.
YouMerge what machines may not, and read "Go to read here".
8

Leave it findable

What was learned outlives the session that learned it.

CoordinatorDated note by PR, a handoff, bites with triggers.
YouSay what bit you. It becomes a rule, not a memory.
HubCarries it into station 1 of the next session.

What flows back

GitHub keeps the code. The hub keeps what the team learned, and serves it first next time.

  • Rules Never force-push. Lanes never delegate. Every PR passes the gate.
  • Decisions Go over TS. VM over Cloud Run. Plugin before daemon.
  • Bites What bit us, with a trigger. Shown before the command runs.
  • Facts Measured, with an expiry.
  • Handoff Where the track is right now. Read first.
